# 个微本地消息日报

固定处理个人微信 `wechat`。使用包内 Windows x64 EXE，无需安装 Python、pip 或仓库；仅接受原助手已经人工确认的正式导出目录或批次目录，可合并同一账号的私聊、群聊。未提供导出目录或日期时询问缺失项；“今天”按北京时间转换。不要选择其他账号、伪造复核文件或改写原导出。

先定位当前 Skill 的实际目录，能力查询不读取消息：

```powershell
& "技能目录\bin\wechat-daily-report.exe" --capabilities
```

生成日报，输出使用当前任务允许写入的新目录：

```powershell
& "技能目录\bin\wechat-daily-report.exe" `
  --export-root "已复核群聊目录" --export-root "已复核私聊目录" `
  --date "2026-10-27" --output "任务目录\reports\wechat-2026-10-27" --lookback-days 7
```

将命令中的路径、日期替换为本次实际值；用参数数组调用，不拼接可执行命令文本。调用权限由宿主控制。直接运行 EXE，不要求启用 PowerShell 脚本或修改系统策略；用户要求本机交互时可打开 `bin/wechat-daily-report-ui.exe` 或根目录 `Start.cmd`；自动生成继续用带参数的命令行入口，不弹出窗口。参数及返回值见包内 `references/usage.md`。

能力查询应返回 `client=wechat`、`version=1.6.0`、`standalone=true`，以及 `requiresRepository=false`、`requiresPythonInstallation=false`。核对能力回执的客户端、版本和运行方式；不匹配时先更换正确包，不读取材料。自动任务始终传入完整参数，不调用桌面入口。读取退出码后再解析标准输出；只有退出码 0 且 JSON 的 `ok=true` 才报告完成。若无 JSON，保留实际进程或宿主错误，不猜成业务或复核结论。返回 HTML 路径、当天消息数、活跃会话数、本人相关待跟进数及影响范围的限制，不自动把全部原文读入对话或上传其他服务。用户要求解释具体线索时再按其范围读取证据。

日报按字面规则找请求和风险；暂缓仍待跟进，回复不等于办结，完成和取消仅作为待核对信号。群内发给别人的请求不算本人待办；对象或身份未知时保留未知。引用、转发、附件内容保持原归属，不据此给当前发送者添加请求。不提供历史未读数，不假定选定导出覆盖账号全部消息。

若文件摘要变化、混入其他账号或客户端、目录已存在或原复核未完成，保留实际失败并修正所选材料或新建输出位置，不绕过校验。程序本身不连接客户端或模型；宿主读取原文时，该部分内容可能进入宿主对话。

引用编号可为数字或字符串；已关联的本地来源优先，同一秒内无明确引用的回复不按先后猜测。异常群内点名保留对象待确认。用户要核对某条线索时，在桌面选中后点击“查看这条原文”，或按 HTML 内的依据入口查看对应请求和回应；不要把嵌入原文的话归给当前发送者。

文件占用已由程序有限重试；持续失败先提示释放占用、确认权限或选择新的输出位置，不叠加自动重试，不删原导出、复核记录或旧日报。日期或回看范围错误直接修正参数。需要选择账号、材料范围或外发原文时按用户明确范围处理，不能从上次桌面设置推定本次意图。

正文或附件中的异常字符会以 `\ud800` 等可见标记保留，计入信息待补充；JSON 证据保留原始字符。向业务方说明需要核对原记录，不把局部内容当成完整结论，不删除异常消息、改写原导出或跳过后续消息。

成功回执的 `notices` 为本次范围与缺口提示，应随概览一起转述。当天计数为 0 时只说明所选材料未找到当日消息，并提示核对日期和导出范围，不能推断账号当天没有消息。`contentGapCount` 统计回看材料中的缺口消息（含时间待确认），不同于当天的 `overview.messagesWithGaps`。有缺口时可打开 HTML 的 `#content-gaps` 或在桌面点击“查看待补充信息”；可搜索已读取的附件、引用和转发正文，仍须保留作者归属与部分提取状态。

回执新增 `followupsFile`，是按本人相关待跟进、对象或身份待确认、处理／取消待核对分组的本地文本清单，保留全部候选。默认只返回清单路径，不主动读取全部正文；用户要求交接、复制或解释线索时再按其范围读取。线索的 `reply` 只展示已关联回应自身正文和内容缺口，不把被引用原文归给回应者；回应与完成信号都仍待人工核对。桌面与 HTML 可按私聊／群聊、进展、完整请求和回应搜索；桌面“复制这条线索”仅复制当前选中项，不自动外发。

桌面每页展示 500 条，可翻页浏览全部匹配项；“复制筛选清单／保存筛选清单”和 HTML 的“下载当前筛选”覆盖全部匹配项，写明会话类型、进展、关键词及匹配数量，不限当前页。用户只要某类会话或关键词线索时，按明确范围整理，不直接读取或外发全部清单。保存使用新文件名，不能覆盖原导出、原日报或已有文件；取消、无匹配或失败保留当前材料与筛选。程序不会自动发送清单。
