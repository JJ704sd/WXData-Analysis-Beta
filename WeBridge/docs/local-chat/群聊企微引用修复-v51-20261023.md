# 群聊 v51：企微引用索引修复

桌面 v51 / 群聊 Skill 1.37.0。私聊独立包仍为 1.7.0。

## 问题与修复

远程 v50 最新诊断记录：149 个群，22 个成功、127 个失败。127 次失败均为 wecom_archive.py:234 的 IndexError，发生于引用索引构建。

当 SQLite 表使用 message_id INTEGER PRIMARY KEY 时，SELECT rowid 返回的列名为 message_id，按 rowid 取值会失败。实际远程表结构未随日志提供；该结构已在合成数据库复现相同堆栈。查询现改为 rowid AS __offline_rowid，两类引用索引都按该显式列名取值。不增加重试、吞错或新的生产依赖，不改变持久化格式和引用匹配规则。

## 验收范围

通过桌面会话公开入口覆盖普通整数列与整数主键、两类引用标识，验证解析、复核后导出 JSON、JSONL、Markdown；保留跨表歧义和跨群匹配的已有检查。最终 EXE 检查企微含两类引用的主键表及个微基本解析、窗口启动、诊断导出。只执行此次修复相关检查，不重跑无关 OCR、媒体大文件和全套 UI。

合成验证不能证明远程 127 个群全部恢复，实际成功率以升级后的诊断与导出为准。本修复不补造未缓存原件。
