# v54 / 私聊 1.8.1 异常中断恢复

## 目标与证据

继续处理此前大批群解析失败暴露的中断问题。已有 v51 引用列名修复、v52 附件 Unicode 修复和 v53 正文复用继续保留。此次没有收到新的远程日志，不推断远程主机目前仍发生相同错误。

v52 本地复现曾在 Unicode 异常后产生 Windows 文件被占用错误。本轮通过 DesktopSession.prepare_review 的进度回调模拟解析中断，并保留异常堆栈，复现个微私聊、企微群聊与私聊快照文件无法重命名。个微群聊同样纳入验证，但此样本修复前未失败。

## 修复范围

SQLite 连接关闭不代表所有未完成语句都已释放；异常堆栈会继续引用合并读取器及其游标。两端的消息游标与连接共同纳入现有 ExitStack，按逆序先关闭游标再关闭连接。只修复资源生命周期，不添加捕获整群异常、无限重试或强制清缓存。

不改变消息、人工复核、导出、画像持久化格式和账号绑定规则，不新增依赖。群聊 Skill 1.39.1（桌面 v54），私聊 Skill 1.8.1 使用同轮构建。

附件子进程异常退出单独探测：退出码 7 约 0.31 秒返回 failed 并保留原件，没有复现等待 15 秒问题，不修改该路径。
