# 源码开发与打包

本源码副本基于 v80，维护个微／企微群聊和私聊四类助手。供应商画像材料开发版本为群聊 v81／1.51.15、私聊 1.20.13；副本内日报为 1.4.0。安装和运行见 [README](README.md)，维护与构建见 [维护说明](docs/maintenance.md)。

时段分析共用 `offline_period.py`，桌面及 `--period-analysis-json` 入口均读取明确选择的已复核导出。HTML、Markdown 与完整证据由同一批筛选结果生成，根消息时间决定范围，未知时间单列，原始字段与出处保留。

供应商画像材料由 `offline_supplier.py` 读取已复核导出，桌面入口及跨会话命令行用法见 [供应商画像材料](WeBridge/docs/local-chat/供应商画像材料-v81.md)。

使用 `WeBridge/scripts/build_all_chat.ps1` 构建四类包，版本以 [chat_release.py](WeBridge/scripts/chat_release.py) 为准。source-manifest.json 与 SHA256SUMS.txt 记录本副本的源码文件字节。真实账号、数据库、密钥和缓存不应纳入源码或分发包。

聊天查看及优化范围见 [查看器说明](WeBridge/docs/local-chat/聊天记录查看器-v79.md)和 [性能与稳定性说明](WeBridge/docs/local-chat/性能与稳定性-v80.md)；时段快捷选择检查见 [v78 验证记录](docs/presets78-validation.json)。修改账号绑定或启动逻辑时遵守 [项目指令](WeBridge/AGENTS.md)。
