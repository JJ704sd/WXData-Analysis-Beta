# 常用时段快捷选择

v78（群聊 1.51.12、私聊 1.20.10）在四类助手的“时段分析…”窗口加入“常用范围”下拉框。

| 选项 | 实际范围 |
| --- | --- |
| 今天 | 今天整天 |
| 昨天 | 昨天整天 |
| 近7天 | 今天及之前6天 |
| 近30天 | 今天及之前29天 |
| 本周 | 本周一至今天 |
| 上周 | 上周一至上周日 |
| 本月 | 本月1日至今天 |
| 上月 | 上个自然月整月 |
| 自定义 | 手动选择起止日期，可填写分钟或秒 |

所有范围按**北京时间**计算，开始和结束日期均包含在内。快捷范围基于当前日期，不基于聊天中最后一条消息的日期，也不是滚动的168／720小时；当前日期跨月、跨年和闰年时按日历计算。

先解析并人工复核导出需要的联系人／群聊，再点击“时段分析…”，选择对象及常用范围。选择快捷范围后，开始和结束日期自动填好，具体时刻清空，按整天分析。继续修改日期、日历或时刻时，选项会变为“自定义”，手动值保留；切换到“自定义”本身不清空输入。

快捷选项不会自动扩大已有导出范围。材料日期不足时仍会提醒补充解析、复核和导出；选择本周或本月也不会推断尚未取得的消息。后续报告、原文证据、范围校验及人工复核规则沿用 [指定对象与时段分析](指定对象与时段分析-v77.md)。包内 EXE 路径以 `runtime.json` 的 `exeRelativePath` 为准。

本轮只验证日历边界、快捷选择、手动修改、小窗口滚动及四类运行包；详细执行范围见源码仓库 `docs/presets78-validation.json` 和交付清单，真实账号未复测。
