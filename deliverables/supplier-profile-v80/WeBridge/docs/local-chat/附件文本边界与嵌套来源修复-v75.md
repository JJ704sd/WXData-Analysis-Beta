# v75 附件文本边界与嵌套来源修复

v75 更新群聊 Skill 至 1.51.9，私聊 Skill 至 1.20.7；日报 1.4.0 保持不变。本次修复附件正文和企微嵌套来源的缺口，保留原始字节、账号范围、出处和人工复核门槛。

## 附件正文中的控制字符

附件正文中的非排版 C0 控制字符不再被静默删除，而是以可见的 `\uXXXX` 形式保留，并标记为部分提取、需要复核，避免 `金额10`、NUL、`0元` 被误拼成 `金额100元`。VT、FF 作为排版字符转换为换行，CR 按既有规则归一为换行；正常中文、emoji 和 Tab 保留，不因这些字符本身新增部分提取状态。

## 企微转发与引用来源

企微转发或无效引用信封缺少 `sender` 或 `time` 时，不再用字符串 `0` 或时间 `0` 补造来源。程序使用既有的未知 ID 和空时间约定，并记录 `metadataIssues` 和部分解析提示；明确提供的数值 `0` 仍保留，正常元数据及引用匹配规则不变。嵌套消息原始 bytes 继续保留，缺少来源时需要结合原记录核对。

## 使用与验证边界

更新后请重新解析受影响的会话，检查附件正文、嵌套消息来源和缺口，再按原流程完成人工复核后导出；旧预览不会自动重写。具体版本、验证范围和未覆盖环境以 [版本与验证说明](版本与验证说明.md) 和交付清单为准。没有对应原件或来源信息时，本修复不会补拉云端内容，也不会把部分解析当作完整成功。

本指南随群聊和私聊相关包提供，链接按包内文件布局编写。编译包、真实账号、原故障电脑和宿主导入结果以交付清单中的实际记录为准。
