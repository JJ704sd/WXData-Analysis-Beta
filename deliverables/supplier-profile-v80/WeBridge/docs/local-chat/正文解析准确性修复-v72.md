## XLSX 注音混入

部分 XLSX 生成器会在共享字符串或 `inlineStr` 中同时写入正文和 `rPh` 注音节点。旧读取路径把这些节点一起拼进单元格值，导致正文出现重复或不应显示的注音。v72 复用经典批注已有的文本排除规则，只读取存储的正文文本，不把 `rPh` 注音加入单元格值。工作表、单元格地址、原始值、公式缓存和消息出处的既有保留规则不变。

## DOCX 域与超链接目标

DOCX 的简单域 `fldSimple` 和同一文本块内跨 run 的复杂域可能保存可见文字与 `HYPERLINK` 指令的不同部分。旧路径能保留部分文字，但可能丢失链接目标。v72 在不执行域的前提下，保留已存显示文字，并从 `HYPERLINK` 指令记录链接目标、内部书签或本地路径。字段不会打开目标、下载内容或执行其他动作；遇到非 `HYPERLINK` 字段不猜测目标。

## 兼容与复核

原件、消息出处、附件状态和既有人工复核继续保留，聊天导出、复核和画像的持久化格式不变。旧预览不会自动重写；需要补齐历史结果时，重新解析目标附件所在会话，再由人工复核后准备导出或画像材料。
