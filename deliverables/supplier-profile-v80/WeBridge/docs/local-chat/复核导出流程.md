  列群、解析、人工复核与导出（v45）

群聊导出区点击“选择位置…”可指定本机目录，程序记住上次选择，每次新建独立批次子目录，记录与已取得的媒体、附件一起保存。已有文件保留原位置，可在“打开文件 → 另存当前群到指定位置…”保存完整副本。外部目录导出的进度需使用v45或更新版本恢复；恢复时保留所选目录及原工作目录缓存。

适用于个微和企微。默认业务流程：确认账号 → 展示全部本地群 ID 与名称 → 勾选群 ID → 批量解析 → 逐群或批量保存人工复核 → 一键导出所选群的 JSON、JSONL、Markdown。

“全部”仅指当前账号本机保存的群索引和消息，不保证服务器端所有群、全量历史或当前成员完整。没有自动登录、发送、云端补拉、OCR、语音转写或外部模型调用。

   桌面操作

1. 个微打开 `Start.cmd`，企微打开 `Start-WeCom.cmd`；在账号设置中确认数据来源。两种客户端独立保存配置。
2. 左侧勾选列支持多选；空格切换当前行勾选，Ctrl+A只勾选当前筛选结果；“全选当前结果”在全选后变为“取消全选当前结果”，勾选表头显示未选/部分/全选并可点击切换。“更多”提供取消当前结果勾选、反选当前结果、全选全部群聊（含隐藏）和取消全部勾选；Ctrl+Shift+A取消当前结果，Ctrl+I反选。“清空选择”清除全部勾选，搜索不会丢失勾选；已选数量包含隐藏群。横向滚动查看完整 ID 与解析状态；“复制所选群 ID”每行复制一个已勾选ID。同名群按 ID 区分。单击群名只切换查看，不解析；双击也不触发解析。搜索框按回车只定位唯一候选，不解析、不更改勾选；重名需按群ID确认。右侧“群资料”显示完整群名与 ID，可点“复制 ID”；左侧搜索框旁“清除”只清空搜索，保留勾选。
3. 点击“解析待处理 N 群”，仅处理尚无预览或日期/媒体范围已变化的目标群；其他群复用本窗口已有结果并保留人工复核，完成提示显示复用数量。按列表顺序逐群处理；每群完成后立即可查看，不必等整批完成。后台解析不再跳走当前阅读群，完成群可切换、翻页、筛选正文、展开转发和查看图片。队列运行时可搜索和调整勾选，本次队列及日期/媒体选项固定，勾选只影响下一次解析与导出；完成或停止后进行人工复核。未勾选时仍可解析当前高亮群。队列固定使用启动时的日期与媒体设置，期间禁止更改来源和范围；日期留空为本地完整范围，结束日包括当天。“停止队列”在当前群结束后停止，已完成结果保留；某群失败单独标记并继续其他群。默认业务阅读仅折叠表情，原始记录仍保留全部类型。所有目标已有相同范围的预览时，主按钮变为“查看待复核群”或“查看已有结果”，只定位查看。需要全部重做时使用独立的“重新解析”，它会重置当前目标的旧复核；首次未选择目标时解析按钮禁用。
4. 有已解析结果后，顶部蓝色完成提示条显示已解析数量、最近完成群与记录数；“查看已解析群”直接切到“已解析可查看”筛选。左侧“解析 / 复核”列无需横向滚动即可区分未解析、排队中、黄色解析中、蓝色已解析·未复核及绿色已复核，不把可阅读当成人工已确认。查看正文、发送者、图片、引用、转发、附件正文及解析状态。单击已解析群名或待复核导航切换，导航显示剩余数量，当前仅剩本群或已经完成时给出对应提示，不重新解析。此时是 `reviews/` 中的内部预览，没有正式导出。列表前部及当前群顶部显示“未复核/已复核”；可筛选所选群、所选未复核或所选已复核，筛选保留勾选。已导出仍显示已复核，底部单列其中已导出数量；重新解析、刷新或范围变化会更新对应状态提示。
5. 点击“复核当前群”，检查账号与群 ID、日期与条数、正文和结构、媒体与解析缺口。四项默认未勾选；可逐项勾选，也可人工点击“全选复核项”，用“清空勾选”取消全部，旁边显示已勾选数量。快捷按钮只作用于当前群本次窗口，不保存、不导出；不足四项时“确认复核完成”禁用。可填写备注。返回检查保留全部预览，其他群继续未复核。存在缺口时，应核对并记录可接受的范围，不能把缺口当作还原成功。
6. 在复核窗口点“确认复核完成”，仅保存该群检查项、备注和确认时间，不导出；“返回检查”不保存确认。首次复核四项均未勾选，再次通过“查看/修改复核”打开已确认群，显示本人本次会话保存的检查项与备注。修改后需再次确认才保存，其他群的复核不受影响。
7. 底部蓝色提示会说明下一步及导出按钮禁用原因，区分未解析、未复核、范围变化、可导出及已导出。所选群均已复核后，点击“一键导出所选群”。存在未解析、未复核或已失效群时不能导出；导出前校验所有目标，再复制已复核的同一批结果，不读取更新消息。
8. “打开批次目录”查看本次所有结果：根目录含batch.json和导出清单.md，每群独立子目录保留三种格式、媒体、复核记录及缺口说明。当前群的“打开文件”菜单提供 JSON、JSONL、Markdown 和阅读材料；“打开目录”定位已保存结果。切换群后按钮及底部路径同步切换；未导出或缺少的文件按钮禁用，没有默认文件关联时尝试系统记事本。部分失败保留成功结果和失败清单，可重试未完成群；已导出群保留原结果并明确跳过，不重复生成。全部已导出时按钮禁用。

多个群可使用“批量复核 · N 群”：确认所有勾选群已解析后打开汇总窗口，一次核对本次各群的账号、ID、日期、条数、解析状态和媒体缺口。四项检查默认未勾选，可人工全选；共同备注应用本次全部目标。点击“确认本次 N 群复核”分别保存各群记录，不导出。已复核或已导出群保留原记录；搜索隐藏的勾选仍在本次范围。返回检查、关闭或Esc不保存；任一目标失效或文件变化时，整批不保存新增复核。之后仍需点击“一键导出所选群”。

复用与恢复均限于已校验的同一副本、相同日期和媒体设置；不自动读取新消息。普通桌面重开可恢复新版已保存的预览、原人工复核、已完成导出、勾选和阅读群，蓝色提示明确显示上次副本时间。需要新数据时点击顶部刷新；明确指定群的新解析与CLI列群仍使用新副本。需要更新本地副本时使用顶部刷新，刷新后旧复核失效。指定群启动请求和“应用日期”仍按明确目标准备新预览。

切换群保留各群的待复核批次和对应导出入口；重新解析成功才替换对应群的复核批次，失败保留旧结果，成功刷新副本或成功切换账号后全部旧复核失效；新来源加载失败保留原复核。修改当前群日期或媒体选项后需重新解析。预览文件变化、源副本变化、未完成复核或取消确认均不能发布正式结果。新版保存的确认可在重开后恢复；仅恢复校验通过的原记录，旧版未保存状态不补写为已复核。确认写盘失败不标记本次确认；已发布结果不会因进度更新中断而重新作为待导出任务恢复。批量选择不合并群记录，各群分别保存 JSON、JSONL、Markdown、复核记录和缺口说明。

引用内容与本地来源关联分别标记：企微已支持的内嵌原文可直接阅读；缺少可验证来源标识时，不代表内嵌原文缺失。未知布局、部分解析或多个来源候选明确保留状态。“待补齐图片/媒体”同时覆盖普通、转发和引用节点。

界面采用统一浅色配色，解析、导出和最终确认使用蓝色主按钮。窗口较矮时自动收起重复说明，保留当前群ID、复核状态、操作提示及文件入口。复核报告带可见滚动条，可按Esc返回检查；关闭或返回均不保存本次勾选。

   命令行脚本

开发者在 WeBridge 目录运行：

```powershell
python scripts/local_chat.py review --client wechat
python scripts/local_chat.py review --client wecom
```

也可提供明确的本地数据与密钥路径：

```powershell
python scripts/local_chat.py review --client wecom --source "D:\my-account\Data" --keys "D:\private-config\database-keys.json" --data-dir ".runtime\review-session"
```

脚本先确认账号、打印全部本地群 ID 与名称，再要求输入完整群 ID 和日期；解析后打印摘要和预览目录。人工检查预览文件，逐项回答 `y`，最后输入 `EXPORT` 才发布正式结果。任一项未通过、取消或输入结束都不确认导出。已有配置失败时不会静默切换账号；普通运行不触发进程取钥。

原有开发者CLI的 `groups`、`export` 和底层批处理 `action=export` 保留兼容，不生成“人工已复核”结论。Skill的 `-Mode Export` 已拒绝，避免宿主绕过窗口复核；需要人工检查的业务使用 `review` 或桌面流程。桌面自然语言启动回执增加 `awaiting_review`，表示等待人工，只有确认并写完正式结果才为 `completed`。命名请求回执只对应原群，不随查看或导出其他群而改变；Desktop多选界面没有批量完成回执。宿主不能替用户勾选或把预览当作已确认结果。

   数据与格式

| 内容 | 输出字段或文件 |
| --- | --- |
| 群 ID、群名、消息 ID、发送者、身份依据、时间与方向 | `chatId`、`chatName`、`id`、`senderId`、`senderName`、`senderIdentityBasis`、`timestamp`、`time`、`direction` |
| 文本、类型、链接、结构化 @、引用、转发 | `text`、`kind`、`links`、`mentions`、`quote`、`record`；未知或未支持类型保留状态 |
| 图片、语音、视频、文件与附件正文 | `asset`、`attachmentContent`、`assets/`；原件取得与正文提取状态独立 |
| 原始数据与出处 | `rawColumns`、`provenance`；跨分片记录保留，不按正文猜测去重 |
| 群成员资料 | `members.json`；本地资料，不推断历史发言者就是当前成员 |
| 完整结构化记录 | `messages.jsonl` 每行一个源消息；`messages.json` 为相同记录的数组 |
| 人工阅读 | `messages.md`、`chat.html`、`业务阅读.txt`；Markdown 与 `assets/` 一起保留 |
| 业务分析材料 | `analysis/`：带 ` 序号` 的分段材料、精简语料、发言人统计和分段索引，随预览生成并纳入复核文件摘要；批量导出另有 `batch-analysis/` 跨群索引 |
| 复核证据与结果摘要 | `review.json` 批量确认时增加batchReview批次ID、本次确认群ID列表和数量；保留账号来源指纹、群 ID、日期、统计、人工检查项、备注、确认时间和所核对文件摘要；`manifest.json` 含输出校验清单与 `humanReview` |

仅提取来源中已有的业务信息，不推测订单、报价、审批或其他业务结论。具体业务字段模板需另有已确认契约。图片/媒体缺失、未知身份、部分解析和未支持企微类型会保留状态，不能宣称已完整还原。

## v42：导出中断与清单恢复

导出时显示当前群和已保存数量。只有正文完成校验并发布才计入已保存；后续群失败不会删除前面的结果。重新打开工具后保持原工作目录，原复核、已完成群及待导出群通过校验后恢复。重试导出只处理未完成群，不重新复制已完成正文。

正文已保存，但 `batch.json`、`导出清单.md` 或 `batch-analysis` 未完成时，点“修复导出清单”。修复会重建清单和跨群分析入口，原正文和附件保持不变；仍有未完成群时会继续标明。磁盘空间不足或文件占用解决后再手动重试，不需要重新解析全部群。

请保留工具工作目录中的快照、reviews 和 exports。恢复按群进行，不是单个大文件的字节续传；首次读取和解密仍需等待稳定副本完成。为只查看已有结果反复刷新会重建副本，应在需要新消息时再刷新。

## v45：失败时保留原会话

账号设置中的“保存并加载”与“导入旧版配置”分别显示。新数据、密钥或配置未通过校验时，继续保留旧来源、原已解析内容和人工复核；修正设置后可重试，也可继续导出原已复核材料。成功加载新副本后再重新解析和复核。

记录有异常时间、字段或附件时，以预览与清单中的具体状态核对；原始值保留，不能把部分可读内容当成完整还原。
