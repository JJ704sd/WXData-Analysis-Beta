## 本轮改进

| 路径 | 原问题 | 改进结果 |
| --- | --- | --- |
| Word 附件 | 内容控件中的段落、表格未进入正文 | 按文档顺序展开，排除删除修订内容 |
| 分析材料 | 引用附件被压缩成附件标签，丢失已提取正文 | 语料保留完整引用内容，阅读材料显示作者与引用边界 |
| 私聊检索 | 只检索消息表面文字 | 检索附件正文、转发、引用、卡片描述及链接，保留根消息出处并显示命中来源 |
| 长附件材料 | 阅读分段只有前 3000 字，宿主未取得全文 | 按本次选定分段提供附件全文补充，增量范围外消息不进入补充材料 |
| 画像依据 | 引用消息可被用于本人/对方的明确表达 | 引用仍可作为观察或待确认依据，不作为本人/对方直接陈述的唯一证据 |
| 位置、名片、小程序 | 关键属性仅在原始结构中或未读出 | 提供可读内容与明确的结构化字段，不推断联系人关系或伪造网址 |
| 正文网址 | 中文标点及后续文字被吞入链接 | 共用链接提取规则，保留可用网址与合法中文路径 |

不新增生产依赖、远程调用、自动重试或吞错逻辑。没有原件、未知协议字段、超限正文和待复核 OCR 仍保留实际状态；不以“导出完成”代替内容完整或业务验收。
