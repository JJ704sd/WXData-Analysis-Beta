# v69 界面滚动与长字段修复

本次修复 v68 群列表和消息列表在小窗口中内容被截断、无法使用滚动条查看的问题，新版为桌面 v69 / 群聊 Skill 1.51.3。

原主题移除了原生滚动条布局并把箭头尺寸设为 0，导致实际滚动条厚度只有 1 像素，难以看到和拖动。群名列与群 ID 列还分别固定为 110、150 像素；即使滚动整个表格，较长字段仍在单元格内截断。

修复保留原生箭头与滑块，并恢复可操作的滚动条厚度。群名和群 ID 列按当前列表的完整文字测量宽度，避免自动压窄后丢失显示内容。表格较宽时，使用底部横向滚动条查看完整字段及右侧列；记录较多时，使用右侧纵向滚动条。也可以拖动表头分隔线调整列宽。

使用临时目录和合成记录进行验证，没有读取实际账号、聊天或密钥：

- 在 1000×700 窗口中拖动群列表和消息列表的横向、纵向滚动条，均能到达末行和末列。
- 长群名、长群 ID 的列宽能容纳完整文字。
- 1000×700 与 1220×820 窗口、Tk 缩放 1.75 下，日期、复核、导出等关键控件仍在可视范围。
- 共 4 项针对性原生界面检查通过。

只修改滚动条主题和列表显示宽度，不改变账号选择、解析内容、人工复核或导出规则。源码启动后立即生效；已有 EXE 需要使用修复后的源码重新构建。本次不向源码仓库上传 ZIP 或 EXE。
