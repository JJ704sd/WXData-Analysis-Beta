# 性能与稳定性说明

适用个微、企微的群聊及私聊工具。个微普通文本解析跳过不可能成功的 XML 解析；包含结构化 @ 的消息继续按原有逻辑检查。原生阅读视图减少重复扫描，并在当前筛选条件不变时复用结果；聊天窗口内的单会话搜索在加载更早记录时读取所需的记录页。首次搜索仍需遍历记录以统计结果，ZIP 来源继续使用原有读取方式。功能不改写聊天源数据；复核和正式导出的原有流程继续适用。

本机合成测试的前后耗时如下，实际速度取决于记录内容、磁盘及电脑状态：

| 操作 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 个微 8,000 条以普通文本为主的解析和复核准备，3 次中位数 | 1.47 秒 | 1.30 秒 |
| 以下 3 项：6 万条混合类型消息 | | |
| 原生阅读建立索引 | 0.72 秒 | 0.38 秒 |
| 原生阅读相同条件翻 120 页 | 0.71 秒 | 0.04 秒 |
| 聊天窗口单会话搜索加载更早的 5 页 | 1.92 秒 | 0.03 秒 |

验证覆盖普通文本和结构化 @、解析前后的消息摘要、引用和转发中的图片、媒体缺失标记、不同筛选条件、大消息、ZIP、并发搜索及原始文件摘要。合成记录和本地检查不能代表真实账号或其他电脑的验收；包含大量媒体、其他复杂消息及首次全局索引的耗时未承诺同等加速。

如果全局搜索提示“本地搜索索引无法读取”，先关闭解析工具和查看器，再检查工具数据目录下 `views/chat-viewer/global-search-index-客户端-群聊或私聊` 对应的索引目录；目录名以实际的 `wechat` / `wecom` 和 `group` / `direct` 为准。可将该索引目录移到其他位置保留备份，重新打开后会重建索引。独立脚本默认索引位于脚本旁 `.chat-viewer-data/global-search-index`，使用 `--data-dir` 时以指定位置为准。请保留源文件、其他缓存和复核资料；处理文件权限或磁盘问题后再重试。
