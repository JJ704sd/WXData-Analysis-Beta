# 配置目录与旧版迁移

适用：桌面 v34、个微和企微独立 Skill 1.20.2。运行库随 EXE 提供，无需安装 Python，没有新增依赖。

## 统一后的存放位置

| 客户端 | 桌面与 Skill 共用的目录 |
| --- | --- |
| 个微 | `%LOCALAPPDATA%\LocalWechatArchive` |
| 企微 | `%LOCALAPPDATA%\LocalWeComArchive` |

在 Windows 文件资源管理器地址栏粘贴上述路径即可打开。`settings.local.json` 保存账号数据目录、密钥文件引用、媒体选项和最近群；`keys` 保存本机恢复或迁移的密钥，`snapshots` 和 `exports` 保存副本与结果。个微和企微各自独立，不能互换密钥。

双击桌面 EXE、桌面 Start.cmd 和 WorkBuddy Skill 都使用相应的同一目录。升级、移动程序文件夹或重新解压不会改变默认用户目录。高级参数 `--data-dir` / `-DataDir` 仍可指定独立工作目录；显式指定其他目录时不自动向其导入旧配置。

## 账号昵称与名称

账号下拉列表在目录前显示可读取的本地昵称/名称，后面保留PID、占用状态和已保存配置标记；主界面也显示当前已加载账号名称。名称来自该目录的联系人/用户资料，按已配置本人ID或目录ID精确查询，旁边注明依据。个微读取nick_name，不把联系人备注当昵称；企微优先用户名称，缺省时显示本地实名字段。昵称是本地缓存资料，可能与客户端最新名称不同；重名仍按目录与进程区分，不用昵称决定账号归属或自动填写本人ID。

普通识别仅复用当前客户端已引用的密钥和本工具keys目录；不会自动读取进程密钥。当前在用账号缺少名称时，可点击“临时取资料密钥并识别运行账号昵称”明确发起只读读取：仅对该资料库的唯一持有进程临时取得资料密钥，核对PID及创建时间，查询本人资料后退出隔离子进程。密钥不写文件、不进入回执；不解析消息、不切换已保存账号。单进程限时30秒，个微累计读取上限4GiB、企微512MiB，企微结构化候选最多4096个。名称仅在窗口会话中缓存，并与目录、PID及启动时间绑定，重启进程后需重新识别。加密资料缺少匹配密钥、无法确认本人ID、目录变化或资料不受支持时显示“昵称未取得”。先选定该账号并完成配置，再点击“重新识别运行账号”；可读取的名称会更新。昵称读取只复制联系人或用户资料库及提交WAL，不查询消息库，不修改原库、不导出聊天、不覆盖现有账号配置。

## 自动迁移规则

1. 固定用户目录已有配置时优先复用，不用旧桌面配置覆盖。已有配置损坏或源路径失效时保留原文件并提示修复，不自动切换账号。
2. 固定目录尚无配置时，查找程序附近、相邻版本目录及当前工作目录和其 build 下的旧 `local-chat-data/settings.local.json` 或 `local-chat-data-wecom/settings.local.json`。只查这些已知名称，不全盘搜索密钥或聊天。
3. 唯一账号的旧配置通过数据库与结构校验后迁移；同一账号多个版本优先尝试最近修改的配置。同账号根目录与 Data/db_storage 子目录兼容。多个不同账号等待用户选择，不猜选。
4. 相对路径以旧配置所在目录为准。只复制配置明确引用的数据库和图片密钥到固定目录的 keys，并改写引用；组合密钥继续使用同一个文件。不搬走原聊天目录、旧快照或旧导出，旧配置和原密钥保留。
5. 校验或写入失败时不发布新配置，可修复后原窗重试。新配置在完整写入后原子发布；迁移可重复执行，已有目标配置不被自动覆盖。迁移不读取微信进程取钥、不解析全部群消息。

## 旧目录不在附近或发现多个账号

“账号设置”标明已保存配置、实际占用状态及已验证的进程PID。已保存账号与唯一在用账号不同，仍保留已保存配置并明确提示差异；由本人点击“选择已确认的运行账号”切换待确认表单，原账号的密钥引用和本人ID不沿用。选择本身不保存或解析，点击“一键自动配置”校验成功才保存。多个在用账号由本人选择；查询失败、目录变化或超过检查上限显示归属未确认，不据此声称唯一运行账号。“未检测到占用”只说明所选数据库未检出该客户端持有，不代表客户端未运行，也不妨碍使用已有密钥加载离线副本。

打开“账号设置 → 手动选择 / 离线副本 → 导入旧版配置…”，选本人所需账号的旧 `settings.local.json`。程序校验并复制引用的密钥，成功后继续原群请求，无需逐个填写路径。此操作会按你的明确选择更新当前客户端配置，另一个客户端配置不受影响。

若旧路径已无效，仍需在手动页选择实际存在的数据或密钥；只有配置文件无法补回已删除的数据库、密钥和媒体。旧导出留在原目录，需要时从原位置查看。升级前可保留旧目录备份，确认迁移成功后再整理。

## 换电脑与分发

固定目录属于当前 Windows 用户。换电脑或更换 Windows 用户，仍需在该电脑首次确认账号并完成自动配置；不能仅复制 EXE 就取得另一台电脑的数据和密钥。

完整包内含Python/Tk、数据库解密和解析组件，不依赖开发机的Python或安装路径。按目标用户的文档路径、个微注册表数据路径及实际数据库占用发现账号；自定义企微目录未发现时可手动选择。请在目标电脑登录账号，在“账号设置”识别昵称、确认账号并点“一键自动配置”，校验解密副本后再选群分析。个微自动配置保持30秒限时，累计只读预算调整为4GiB；企微无密钥管理实例时也可使用结构化字符串备用路径，必须通过全部所选加密库的验证，不能仅凭昵称资料库成功就认为聊天库可解密。

适用Windows 10/11 x64及现有支持的个微4.x、企微5.x格式；客户端布局或加密格式变化、读取权限不足、未登录或缓存缺失时仍可能失败，可使用匹配密钥或已解密副本。另一台实体电脑尚未实测，不将本机验证写成跨电脑验收。

对外转发原始交付 ZIP。不要打包使用后的用户配置目录、keys、snapshots、exports 或聊天数据库。已有本机 Skill 配置无需导入，升级后直接复用。
