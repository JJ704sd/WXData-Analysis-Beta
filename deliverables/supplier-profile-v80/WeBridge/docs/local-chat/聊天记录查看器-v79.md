# 聊天记录查看器

企微、个微的群聊和私聊工具共用此入口：选择会话并完成解析后，在窗口中选中该会话，点击 **打开聊天窗口**，浏览器会打开对应的本机聊天预览。重复点击其他已解析会话，可在查看器中切换；支持当前会话查找、跨已接入会话搜索及结果定位。

聊天窗口读取解析工具已有的本地阅读缓存，标记为“解析预览”；即使查看过，仍需在解析工具中按原流程人工复核，确认后才能正式导出。群聊后台批量解析期间，也可查看已完成并选中的会话。

查看器随 Windows 桌面程序一起打包，使用程序自带的 Python 标准库，不需要另外安装 Python、数据库服务或 pip 包。浏览器页面由解析工具在 `127.0.0.1` 提供；关闭解析工具、成功切换数据源或清除账号缓存时，本次页面随之停止。重新打开解析工具并选中已有解析结果后，可再次点击按钮。

查看器也可接入包含 `manifest.json` 和 `messages.jsonl` 的 WeBridge 正式导出目录或 ZIP；记录和附件以导出或缓存中的实际内容为准。首次全局搜索会在工具自己的本地数据目录中创建索引，数据量大时需要额外时间和磁盘空间。源聊天数据、解析缓存和导出不会因查看而改写。

群聊和私聊分别维护搜索索引；同时打开同一类型的多个窗口时，各窗口的索引互不干扰。清除该客户端的账号缓存时会一并清除查看器索引，原始数据和正式导出保留。

验证以本次交付记录为准。合成账号、源码和打包检查不能代表真实账号、目标电脑或宿主环境的验收结果。
