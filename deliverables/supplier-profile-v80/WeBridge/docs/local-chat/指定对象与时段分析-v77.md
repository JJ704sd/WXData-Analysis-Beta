# 指定对象与时段分析

v77 增加独立的“时段分析”入口，适用于个微／企微的群聊和私聊。群聊版本 1.51.11、私聊版本 1.20.9；消息日报仍为 1.4.0。

## 桌面使用

1. 在对应助手中选择账号和目标联系人／群聊，解析需要的日期范围，核对消息、附件及缺口，完成人工复核和正式导出。
2. 点击底部“时段分析…”，或“更多设置 → 指定对象与时段分析…”。窗口只列出当前账号已经正式导出的会话；支持多选、全选，以完整 ID 区分重名。私聊表示与所选联系人的双方对话，群聊表示所选群的整个对话，不是仅筛某一群成员的发言。
3. 选择开始和结束日期，可填写具体时间 `HH:MM` 或 `HH:MM:SS`。全部使用北京时间；时间留空表示整天。结束日期含当天，结束分钟含整分钟，结束秒含该秒。例如 `09:00` 至 `18:00` 包含 `18:00:59`；填 `18:00:00` 则只包含到该秒。
4. 选择保存位置，程序在其中新建“时段分析-时间戳”目录，后台生成后打开 `report.html`。可搜索正文、附件、发言人和会话，区分时段内与时间待确认的依据，点击线索跳转并展开原文。

已导出日期不足时需要重新解析并复核对应范围后再分析。不同导出日期之间的空档会提醒；本地缺失的历史消息不会自动补齐。重新解析当前会话后，应以新结果重新复核导出。原始数据库、正式导出和画像库不会被分析功能改写。

## 输出内容

| 文件 | 用途 |
| --- | --- |
| `report.html` | 可搜索、可滚动的离线报告，包含各对象条数、按日统计、关键词主题、请求与回应线索、紧急用词和内容缺口 |
| `report.md` | 报告和按时序排列的可读原文，包含引用、转发与已提取的附件全文 |
| `report.json` | 请求范围、统计、线索、来源、复核信息和限制 |
| `evidence.jsonl` | 每条消息的稳定 `evidenceId`、原消息 ID、来源导出与行号、复核编号、完整 `originalMessage`（含原始字段与出处） |
| `分析任务.md` | 供宿主继续整理需求、结论、进展及待核实事项的任务文本；结论需引用 `evidenceId` |
| `manifest.json` | 输出文件大小与 SHA-256 校验清单 |

分析功能只读取明确选择并通过复核及摘要校验的材料。同一账号同一会话的重复导出按稳定消息 ID 合并并保留全部出处；同 ID 内容冲突时提示选择一致版本。不同账号不能混合分析。原件保留在正式导出目录，本报告不再次复制图片或附件。

时段按**根消息发送时间**筛选；根消息携带的历史引用、转发或附件作为上下文保留，不计为额外消息，也不把第三方陈述归给当前发送者。时间缺失或无效的消息单列保留，不能确认属于本时段，不参与统计、主题或跟进判断。

主题与跟进使用字面规则，不是模型对业务结果的确认。只在所选时段内寻找请求与后续回应，时段外的回复不参与判断；未找到回复不代表未处理，完成或取消措辞也仍需核对。需要进一步语义分析时，把生成目录和 `分析任务.md` 交给已授权的宿主，脚本不会自动上传材料或调用模型，画像仍沿用独立复核流程。

## 源码与包内命令行

在当前包外创建 UTF-8 的 `period-task.json`，将路径和完整 ID 替换为自己的已复核导出。可以提供多个同账号的导出目录，或含 `batch.json` 的批量目录；`chatIds` 必须明确指定，不按名称猜测。

```json
{
  "exportRoots": ["D:/ChatExports/reviewed-batch"],
  "chatIds": ["<从当前账号列表复制的完整会话ID>"],
  "start": "2026-10-27 09:00",
  "end": "2026-10-28 18:00:00",
  "output": "D:/PeriodReports/new-report"
}
```

从仓库根目录执行（Windows，使用既有项目环境）：

```powershell
.\.venv\Scripts\python.exe WeBridge\scripts\local_chat_bootstrap.py `
  --client wecom --conversation-mode group `
  --period-analysis-json D:\Tasks\period-task.json `
  --result-json D:\Tasks\period-result.json
```

在独立 Skill 包中，先读取 `runtime.json` 的 `exeRelativePath`（群聊文件名带版本号，私聊为 `bin/local-chat-desktop.exe`），以该 EXE 替换上述 Python 与脚本部分，参数相同；私聊包使用 `--conversation-mode direct`，个微使用 `--client wechat`。程序校验包绑定，不允许跨客户端或跨会话类型调用。命令行不打开窗口，通过新的 `--result-json` 返回成功、统计或错误；目标报告目录和结果 JSON 均须不存在。

## 验证范围

本轮使用合成材料检查四类解析、复核、导出至时段分析路径，以及精确会话选择、北京时间边界、重复材料、未知时间、原始出处和小窗口滚动。实际执行记录见源码仓库 `docs/period77-validation.json` 及交付目录；真实账号、原故障电脑和 WorkBuddy 宿主内的实际调用需在对应环境复测。
