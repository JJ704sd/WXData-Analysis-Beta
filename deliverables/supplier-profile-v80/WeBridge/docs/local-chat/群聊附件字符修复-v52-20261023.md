# 群聊 v52：异常附件字符修复

桌面 v52 / 群聊 Skill 1.38.0；私聊独立包仍为 1.7.0。

## 证据

v51 远程日志显示当前已解析 148 群。当前会话中 126 次群解析完成；同一群两次报 UnicodeEncodeError，堆栈均在 offline_chat.py:722 写业务阅读文件时。包内另有旧 v50 会话的 127 条 IndexError，不能计为 v51 新失败。程序摘要与发布的 v51 一致。

## 修复

合成 PDF 的 ToUnicode 字符表映射到孤立 UTF-16 代理字符时，文档库会原样返回，后续 UTF-8 写出拒绝该字符，导致整个临时导出撤销。本机已复现与日志相同错误位置；真实远程附件未包含在日志内，不能据此确定其具体文件、格式或字符。

仅在附件正文提取入口处理字符：成对代理字符还原为合法字符；孤立代理字符保留为可见 \uXXXX 转义，正文标为部分提取并要求核对原件。正常中文、数字、表情和源附件不变，后续消息继续处理。不增加重试、吞错或生产依赖，不更改历史文件。

## 必要验证

使用实际合成 PDF，覆盖个微和企微解析、阅读视图、人工复核后的三格式及业务语料导出，确认原件字节一致、异常内容有提示、后续消息保留。正常中文与非 BMP 表情对照；保留 v51 两类引用及跨群匹配回归，检查新版本和诊断入口。最终 EXE 验证两端同类附件和引用、启动与日志。未扩跑无关大文件、OCR、全套 UI 和全仓测试。
