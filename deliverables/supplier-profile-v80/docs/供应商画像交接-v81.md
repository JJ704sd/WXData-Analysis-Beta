# 供应商画像材料交接

本页保留 v81 历史交付记录；当前版本与检查结果见 [v82 交接报告](供应商画像交接-v82.md)。

本次交接个微／企微的群聊、私聊四类助手：群聊 v81／1.51.15，私聊 1.20.13。新版在 v80 聊天查看和时段分析的基础上，增加供应商画像材料及可回查证据。原 `WXData-Analysis-Beta` 根目录的日报 1.8.0 继续独立使用；此源码副本附带的是历史日报 1.4.0，不应拿它覆盖 1.8.0。

## 使用资料

从 [v81 发布页](https://github.com/JJ704sd/WXData-Analysis-Beta/releases/tag/chat-assistants-v81)按客户端和群聊／私聊类型下载一个 ZIP，完整解压后运行 `Start.cmd`。也可从 [源码首页](../README.md)进入。登录并确认有权读取的账号后，选择供应商相关会话和日期，解析、检查缺口并完成人工复核导出；再选择“更多设置 → 供应商画像材料…”。详细步骤、命令行任务和结果格式见 [供应商画像材料说明](../WeBridge/docs/local-chat/供应商画像材料-v81.md)。

使用者自行确认供应商名称，以及每个群中属于该供应商的发言人；群内其他人仅作上下文。私聊对方 ID 未确认或发送者不匹配时不自动归属。报告按产品、报价、能力、区域、交付、结算、订单、售后和跟进整理关键词线索，引用原文、导出复核编号和消息行号；关键词、否定句、问题及历史说法均需人工复核，不能直接当作确定的价格、资质或履约结论。

桌面入口处理当前助手、当前账号和会话类型的已复核导出。需要合并同一客户端、同一账号的群聊和私聊时，可使用 Windows 包内 `--supplier-analysis-json` 或源码脚本，显式列出会话及群成员 ID。个微、企微和不同账号的材料不自动合并。原始数据和正式导出保留在原位置；草稿模板应复制后填写。

## 已验证与待接手事项

2026-11-03 在 Windows、Python 3.14.6 环境下，27 项相关源码检查通过，涵盖四类桌面入口、供应商对象归属、已复核来源与路径保护、时段分析及打包。另将四个 ZIP 分别解压，在系统 Python 不在 PATH 且 Python 环境变量已移除时实际运行各自 EXE 的画像任务；四类组合均验证了发言归属、时间未知消息、报价线索原文、导出复核依据和错误客户端拒绝。记录见 [源码检查](supplier81-source-validation.json)和 [程序包检查](supplier81-package-validation.json)。
